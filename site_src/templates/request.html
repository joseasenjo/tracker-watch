How it works

1. Ask

Pressing the button opens a GitHub issue with the address already filled in. You review it and submit it. Nothing is sent from this page.

2. Automatic check

A workflow validates the address (public websites only), applies the limits, and then measures it or creates the link. Nobody approves it by hand.

3. Reply

The result is posted in the same issue, which is then closed. A new short link goes live a few minutes later, once the site has been republished.

What to know

  • Public. The issue, your GitHub account name and the address you enter are visible on GitHub. Do not enter anything private, and do not include personal data.
  • One measurement. An analysis is taken from servers in the US at one moment, with no clicks. It is not added to the weekly ranking and the counts are not verdicts: see the limits.
  • Refused addresses. Private or local addresses, addresses with credentials, other link shorteners and blocked domains are refused, and so are requests beyond the limits above or from blocked accounts.
  • Removal. We can remove any short link at any time, for example if it leads to harmful or misleading content. If you see one, tell us.
