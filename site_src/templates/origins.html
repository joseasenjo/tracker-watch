How to read this

  • The measurements were taken from: {% for o in origins.origins %}{{ o }} ({{ origins.dates[o]|join(', ') }}){% if not loop.last %}; {% endif %}{% endfor %}. Each origin is one machine on one network, at one moment.
  • Consent tool says whether a consent-management service in our list was contacted. One possible cause of a gap is a consent wall that appears in some countries and not in others, but this page does not prove that is the cause: our list of consent tools is limited, so “not seen” does not mean “absent”, and the column does not line up consistently with the gaps.
  • Other possible causes: advertising and tests that differ by country, different content delivery paths, and ordinary run-to-run variation. Each figure is a median of several passes, which reduces but does not remove the last one.
  • A gap is not a verdict on any site. It shows that a single number depends on the vantage point.

Measure it from your country

Anyone can add an origin. You run the same open scanner on your own computer and send the reports in a pull request. It takes about half an hour for the whole list; the scanner makes a handful of ordinary page loads per site, spaced out, and never clicks anything.

  1. Install the tool (repository, see its README) and run it from your home or office connection, not through a VPN or proxy unless you say so in the label: 
    python -m traceguard --sites-file data/sites.json --vantage your-slug --out my-scan
  2. Check and copy the reports into the repository: 
    python -m traceguard.community add my-scan/YYYY-MM-DD --slug your-slug --label "Your country" --contributor your-handle
  3. Open a pull request with the new data/community/your-slug/ folder. A check validates the files; a maintainer reads the pull request before it is merged.
  • Reports are accepted only for the sites already in our list, with at least 2 passes and an observation window of 8 to 60 seconds. They must contain no query strings and no cookie values (the scanner never writes any).
  • Whatever the file says, the counts shown here are recomputed from the raw request log, and the origin is always labelled community, unverified.
  • Your handle is published next to the data. Use anonymous if you prefer.
