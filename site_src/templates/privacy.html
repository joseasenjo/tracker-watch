Privacy

This website

This website is a set of static pages. It sets no cookies, runs no analytics, loads no fonts, scripts or images from other sites, and keeps no visitor logs of its own. The script on the page only handles the filters and sorting in your browser and stores nothing.

The pages are served by GitHub Pages. GitHub, like any web host, may process technical data such as your IP address when you request a page; see GitHub's own privacy statement.

Browser check

The Browser check page reads details of your browser only when you press its button. The reading happens inside the page: nothing is sent to us or to anyone, and nothing is stored. The two optional checks, each with its own button, contact other servers from your browser. The tracker test makes two requests to each of seven advertising and analytics servers (it only requests a script, never runs it) and one to this site; the connection check makes requests to Cloudflare (its public connection page and its public WebRTC server). Every server is listed on that page, before the button. Those companies see what any request carries, such as your IP address; we send no cookies and no referring page, and we never receive the results, which are shown only to you.

Requests: analyses and short links

If you ask for an analysis or a short link, you do it through a public GitHub issue, processed automatically by GitHub Actions. The issue, your GitHub account name and the address you enter are visible on GitHub and governed by GitHub's terms. We use the account name and its age only to apply usage limits. Analysis results stay in the issue. A short link is stored in the repository (code, destination, date and a summary of what we measured) and published on this site. This website itself still sets no cookies and collects nothing.
