Short links

Short links that show where they lead before you click.

Ask

Open a request with the address you want to shorten and, optionally, the code you would like. Anyone with a GitHub account can, and nobody approves it by hand.

Automatic check

A workflow checks the address, applies the limits, measures the destination, creates the link and replies in the issue. The site republishes a few minutes later.

Check before you go

The link opens a page with the destination, what we measured there when available, and a button to continue. Nothing redirects by itself.

Rules

  • Only http and https addresses on public websites. Addresses that point to private networks, carry credentials, or belong to other link shorteners are refused.
  • Limits per GitHub account: {{ limits.links.per_account }} every {{ limits.links.window_hours|span }}, {{ limits.links.global_per_day }} per day for the whole site, and at most {{ limits.links.max_total }} links in total.
  • We may remove a link at any time. See "Reports and removal" below.
  • The page shows counts of what the destination contacted, not a judgement about it. A link here is not an endorsement of the destination, and we do not control what it shows later.

Reports and removal

  • How to report a link.{% if repo_url %} Open a report (public: do not include personal data){% else %} Use the report form on the project page (public: do not include personal data){% endif %}{% if contact_email %}, or write to {{ contact_email }} if you prefer not to do it in public{% endif %}. Anyone can report, with or without an account on this site.
  • What we remove. Links that lead to phishing or scams, malware, content that is illegal, or content that is misleading, harassing or abusive; links that infringe someone's rights; links made to hide a destination or to abuse this service; and any link its creator asks us to remove.
  • How fast. We aim to review each report within 3 working days. When a link looks like phishing, malware or illegal content we remove it first and review afterwards. This is a small project run by one person, so these are goals, not guarantees.
  • What removal means. The link page disappears when the site is republished (a few minutes after we remove it) and the code is not reused for another destination.
  • Who is told. For a link made through a request, we comment on the original issue with the reason; the person who reported it gets an answer in their report. If you think we removed a link by mistake, write to us and we will look again.
  • What we keep. The code, the destination address, the date, an optional note and the measurement shown on the link page. The request issue, including the GitHub account name, stays public on GitHub. See the Privacy page.
