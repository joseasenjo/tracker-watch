What this is

{{ site_name }} measures, every week, which third-party tracking services news websites contact when a page is loaded with no clicks and no consent given. The method, its limits and the list used to classify services are public on the method page, and every report is published as raw data.

Corrections and right of reply

Mistakes are possible: a domain can be attributed to the wrong operator, an outlet's own domain can be missed, a page can behave differently for a reader in another country. If you represent a listed site, or you spot an error, tell us:

We re-check what is reported, correct what is wrong, and record each correction in the data and on this page. We do not remove a site from the list at its request, but we will state its reply next to its results.

Independence

No outlet pays for, or is paid by, this project. At the moment it has no income and no affiliate links. If that changes, it will be disclosed on this page before it starts, and it will never influence what is measured or how it is classified.

Reproducibility

Each report records the tool version, browser, locale, time zone, user agent and the place the scan ran from, plus the request log of every pass (without query strings or cookie values). The latest table is available as CSV.

Changes to the method

  • 2026-10-04, same version: the classification list grew from 60 to 147 entries (mostly advertising and identity services) and the band ranges were revised from A 0–2, B 3–5, C 6–9, D 10–14, E 15+ to A 0–2, B 3–9, C 10–24, D 25–49, E 50+, because the larger list moved many counts far above the old top band. All earlier figures were recomputed from the same raw measurements; nothing was measured again. The new entries identify vendors from general knowledge and are marked as unverified on the method page.
  • Version {{ tool_version }} (first public version): counts of third-party tracking services before any interaction, three passes, median, fixed bands A–E, small hand-built classification list.
